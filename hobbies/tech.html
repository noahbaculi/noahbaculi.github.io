Community Technology

We use technology in so much of our lives in this modern era. It's very gratifying to help my family and friends with the technology they use everyday, from upgrading computers to switching mobile carrier providers or optimizing home WiFi. I make sure to demonstrate and educate my friends and family to improve their tech literacy and self-sufficiency.

Home Server

I enjoy hosting applications that provide utility cost-effectively and prioritizing privacy. These applications range from file storage and media hosting to security cameras and smart home automations. My main home server is a mini-ITX computer with 3D printed hard drive mounts running Proxmox to orchestrate virtual machines.

Backups

Since I host family photos and other data that cannot be replaced, it's important to backup to multiple destinations in different physical locations. I have a simple external HDD backup on site to more easily recover from smaller events like accidental deletions. There is also an offsite tower backup server with a redundant drive array for large media backups. As a final line of defense, there is a Raspberry Pi that receives backups of irreplaceable data.
